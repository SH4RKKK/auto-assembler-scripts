# auto-assembler-scripts

Cheat Engine Auto Assembler scripts for game memory manipulation. Organized by engine version.

**Language:** Cheat Engine Auto Assembler

## Structure

- `UE3/v1/`: First generation scripts (2019-2021). Speed hack and fly hack, x86 and x64 variants.
- `UE3/v2/`: Rewritten scripts for a private server build (2025). x64 only.
- `UE4/`: Scripts for the UE4 engine version (2021-2023). Fly hack, console tooling, and autoquest automation.

Each subfolder has its own README with details.
